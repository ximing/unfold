## 产品

Unfold 用来梳理概念和关系。结构只有四个名词：合集、点、边、卡片。

卡片只扩展点和边的内容。算法用代码卡片，数学用公式卡片，人脉或历史事件用人物、事件、地点、时段、群体卡片。不为某个领域单独做一套结构。新需求只增加卡片种类。

合集之间可以用边互相关联。点和合集之间没有边。

## 四个名词

**合集**只有标题。新建合集不需要先有点。合集没有父子，没有领域，没有意图说明。

**点**有名字和一句描述。描述不超过 160 个字，直接显示在图上的名字下方。点没有类型。同一用户可以有两个同名的点。一个点可以同时属于多个合集。从合集移出不会删除这个点；一个点可以暂时不属于任何合集。

**边**有方向，标签是用户写的文字，去掉首尾空白后 1 到 40 个字。禁止连到自己。同一用户、同一起点、同一终点、同一标签，在未删除的边里只能有一条。标签不同就可以在同一对端点上有多条边。合集和合集之间的边使用同一套规则。

**卡片**挂在点、点与点的边，或合集与合集的边上。八种卡片在任何合集里都能用。创建之后不能改类型，只能改内容。

| 类型 | 内容 |
| --- | --- |
| 笔记 `note` | 正文 `body`，富文本，存 HTML |
| 代码 `code` | 语言 `language`，源码 `source`，失焦后高亮展示 |
| 公式 `formula` | LaTeX `latex`，界面用 KaTeX 排出 |
| 人物 `person` | 身份 `identity`，备注 `note` |
| 事件 `event` | 时间 `when`（日历选择，也接受手写），地点 `where`，经过 `summary` |
| 地点 `place` | 备注 `note` |
| 时段 `period` | 起 `start`，止 `end`（日历选择，也接受手写），备注 `note` |
| 群体 `group` | 备注 `note` |

标题和名字去掉首尾空白后 1 到 80 个字。

## 怎么用

1. 登录后进入合集全貌 `/library`。
2. 双击空白处新建合集，只填标题；也可以 ⌘N。侧栏列出全部合集和点数。
3. 双击合集打开它。双击空白处添加点，只填名字。
4. 拖动点右缘的圆点，放到另一个点上，写一句标签就连成边。选中时，合集里的其他点和边仍留在图上。
5. 悬停一个点半秒，看到它的描述和卡片摘要。双击点直接改名。方向键在图上移动选中，Enter 打开或改名，Esc 取消选中。在点上或边上添加卡片，失焦后保存。
6. 回到全貌，用同样的方式把合集连到合集。选中一个合集或一条合集边时，其余合集仍留在图上。

空合集显示「先添加一个点」。还没有合集时，全貌显示「还没有合集」。

搜索是 ⌘K。它匹配点的名字，以及挂在点上的卡片文字。命中若还在某个合集里，打开那个合集并选中这个点。不在任何合集的命中显示「不在任何合集」，不能从搜索跳进去。搜索不查边上的卡片，也不查合集标题。

## 图

两张图都是全貌，都用自定义 SVG，放在 `GraphViewport` 里，绘制在 `BoardCanvas` 中。

- 全貌画出每一个合集，以及合集之间的边。合集上标出成员点数。
- 合集图画出每一个成员点，以及两端都在这个合集里的边。一端不在合集里的边不出现。点上标出卡片数和卡片类型的色点，边标签旁标出边上的卡片数——看图就知道内容挂在哪里。

没有边，或者图里有环时，点横排。没有环时，按边从左到右分层。点一个点不会把图收成这一跳的上下游。

地址 `?node=` 和 `?edge=` 会在合集图加载后选中对应的点或边。之后的点击不把选择写回地址。

## 界面

壳层是图标栏、合集目录、画布。目录可以收起。

- 图标栏：标志回到全貌，合集，搜索 ⌘K，新建合集 ⌘N，收起或展开目录。更多里只有登出。
- 目录：平铺的合集链接和点数。空的时候写「还没有合集」。
- 画布全出血，浅灰底加细点阵。新建、连线、改名都在图上直接做；左上角碎屑显示当前合集和点数。
- 选中后，右侧浮出玻璃检查器：合集可以改名、打开、连到另一个合集、看到相关的边、删除；合集边是卡片和删除。点的面板可以改名、放卡片、把这个点也放入其他合集、移出这个合集、删除这个点。边的面板显示两端名字，可以改标签、放卡片、删除这条边。

样式跟组件放在同一目录，令牌在 `apps/web/src/foundation/`。浅色分层灰、毛玻璃、单灰蓝强调。界面用无衬线，笔记正文用衬线，代码用等宽。八种卡片的颜色在 `apps/web/src/features/cards/card-meta.ts` 注册，没有点的类型色标。
