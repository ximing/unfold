## 产品

Unfold 用来梳理概念和关系。结构只有四个名词：合集、点、边、卡片。

合集页 `/c/:id` 是可以亲手摆放的画板。上面有文字点和图片点。点与点之间用有方向的边关联。边的标签在图上直接改。也可以把别的合集放进这张画板里查看和编辑。全貌页 `/library` 仍自动排布，没有这套工具栏，不能上传图片，也不画子集合的边框。

卡片只扩展点和边的内容。算法用代码卡片，数学用公式卡片，人脉或历史事件用人物、事件、地点、时段、群体卡片。长文用富文本卡片。不为某个领域单独做一套结构。新需求只增加卡片种类。

不增加第五个名词。图片不是一种卡片，也不是第五个名词。图片是点的脸。富文本是第 9 种卡片，类型 `rich`，只挂在点上。

合集之间可以用边互相关联。点和合集之间没有边。

桌面客户端打开的就是这份站点。开发窗口是 `http://localhost:5173`，安装包是 `https://unfold.aimo.plus`。安装包里没有第二份页面。登录仍用页面上的 Cookie `unfold_session`。关掉客户端再打开，400 天内不用重新登录。主动退出后要重新登录。

安装包在 GitHub Release `desktop-v<版本>` 下载。覆盖 Windows x64、Linux x64、macOS Apple 芯片和 macOS Intel。站点更新不用重装壳。

## 四个名词

**合集**只有标题。新建合集不需要先有点。一个合集可以放进另一个合集里查看和编辑，放进去的仍是原来的合集，不是复制，也不是第五个名词。没有领域，没有意图说明。

**点**有名字和一句描述。描述不超过 160 个字。点没有类型。脸上是文字或图片，这不是点的类型。同一用户可以有两个同名的点，文字点和图片点都算在内。一个点可以同时属于多个合集。从合集移出不会删除这个点，也不删它的图片；一个点可以暂时不属于任何合集。

**文字点**是圆角矩形，宽 168。没有描述时高 56，有描述时高 74。名字居中。描述在名字下方，最多两行，超出隐藏。卡片数在右上角，卡片类型的色点在底部。

**图片点**脸上是这张图片，下面一行名字作为说明。描述不压在图片上，出现在悬停预览和右侧检查器里。卡片数和类型色点仍在。名字规则与文字点相同：去掉首尾空白后 1 到 80 个字。

图片属于这个点。在任何一个合集里更换图片，其他合集看到的也是新图。删掉这个点时，图片一起删掉。

两种点都能属于多个合集，都能挂原来的八种卡片，也都能挂富文本。两种点都能作为边的起点或终点。文字点和图片点之间没有额外限制。

位置按合集记在成员关系上（`x`、`y`、`z`、`imageWidth`），不记在点上。在这个合集里拖动，不改变它在别的合集里的位置。图片在每个合集里有自己的宽度和叠放次序。

**边**有方向，标签是用户写的文字，去掉首尾空白后 1 到 40 个字。禁止连到自己。同一用户、同一起点、同一终点、同一标签，在未删除的边里只能有一条。标签不同就可以在同一对端点上有多条边。合集和合集之间的边使用同一套规则。

**卡片**挂在点、点与点的边，或合集与合集的边上。原来的八种在任何合集里都能用，点和边都能挂。富文本只挂在点上。边和合集边的添加按钮里没有它。创建之后不能改类型，只能改内容。一个点可以有多张富文本。

| 类型 | 内容 |
| --- | --- |
| 笔记 `note` | 正文 `body`，短文，存 HTML。粗体、斜体、行内代码、标题、列表和引用。不改成富文本 |
| 代码 `code` | 语言 `language`，源码 `source`。编写时按语言高亮。语言在卡片顶栏用下拉切换 |
| 公式 `formula` | LaTeX `latex`，界面用 KaTeX 排出 |
| 人物 `person` | 身份 `identity`，备注 `note` |
| 事件 `event` | 时间 `when`（日历选择，也接受手写），地点 `where`，经过 `summary` |
| 地点 `place` | 备注 `note` |
| 时段 `period` | 起 `start`，止 `end`（日历选择，也接受手写），备注 `note` |
| 群体 `group` | 备注 `note` |
| 富文本 `rich` | 长文。只挂在点上。可含标题、列表、表格、代码、公式、Mermaid 和图片 |

标题和名字去掉首尾空白后 1 到 80 个字。

## 账号

注册开放：`/register` 上用用户名和密码开账号，注册完直接进入，不用重新登录。用户名去掉首尾空白后 2 到 32 个字，不含空白；密码 8 到 72 位。用户名唯一，已被占用时提示「这个用户名已经被用了」。注册后可以改用户名，占用冲突用同一句提示。

头像是一张图片（JPEG、PNG、WebP、GIF，不超过 5 MB），存在私有对象存储里，界面每次拿到的都是服务端现签的临时地址，过期后重新取。没有头像时，账号区显示用户名的第一个字。

## 怎么用

1. 注册或登录后进入合集全貌 `/library`。
2. 双击空白处新建合集，只填标题；也可以 ⌘N 或合集切换里的「新建合集」。合集切换列出全部合集和点数。
3. 双击合集打开它。画板记住每个成员在这个合集里的位置。还没有位置的旧成员，用自动排布算一次起点并记下。算完之后不再自动重排。有环或没有边时横排，无环时从左到右分层。这次只负责给旧图一个起点。
4. 添加文字点：选择工具下双击空白，或按 T 再点击空白。点出现在双击或点击的位置，只填名字。点在已有的点上不会再叠一个新点。从别的合集放进来、这里还没摆过的点，落在当前视野中心。中心已经挡住别的点的左上角时，向右下错开，直到让开。
5. 添加图片点：工具栏的图片或按 I，把图片文件拖进画布，或焦点在画布上时 ⌘V。详见下文。
6. 连线：悬停点时，上、下、左、右各有一个蓝色圆点。从任一圆点拖到另一个点，或按 L。写一句标签就连成边。选中时，合集里的其他点和边仍留在图上。
7. 拖动点到新位置，松手后记下。保存失败时，点回到松手之前的位置，并显示原来的错误。没有移动就松手，只是选中。真正拖动过的点叠到最上面。只点选不改变叠放。拖动过程中不出现悬停预览，也不选中文字。
8. 悬停一个点半秒，在点旁边看到完整描述和卡片摘要。视口右侧放得下就放在右侧，否则放在左侧。整张预览留在可见画布里，不钻进检查器或左侧工具栏。按下并拖动点时不出现这份预览。指针可以移到预览上滚动阅读，离开点和预览后预览才关闭。图片点的预览出现在图片旁边。双击点直接改名。方向键按空间远近移动选中，文字点和图片点都参加。选中点时，Tab 按账号上的下级方向新建下级文字点，默认在下方。Enter 在下方新建同级文字点，规则见下文。选中边时 Enter 改标签。Esc 的规则见工具栏。在点上或边上添加卡片。笔记等卡片停下输入大约两秒后保存，失焦或 ⌘S 也会保存。富文本停止输入大约一秒后保存，失焦或 ⌘S 再保存一次。
9. 回到全貌，用同样的方式把合集连到合集。选中一个合集或一条合集边时，其余合集仍留在图上。全貌上的合集边在检查器里改标签。
10. 插入子集合：左侧「子集合」，或右键空白「插入子集合」。弹窗里选一个合集。规则见下文。

空合集显示「先添加一个点」。画布上已经有子集合时不显示这句。还没有合集时，全貌显示「还没有合集」。合集里点数不超过 2、且没有子集合时，提示为：「双击空白添加文字 · 拖入图片 · 拖动点 · 从圆点拖线或按 L 连线 · 选中点后 Tab 建下级、Enter 建同级 · 工具栏或右键可插入子集合」。

选中点后按 Tab，或右键「建下级」，按账号上的下级方向新建下级文字点，并连一条边。默认在下方。标签先写成「下一级」，之后可以改。Enter 在下方新建同级文字点，不自动连边。同级不看下级方向。

搜索是 ⌘K。它匹配点的名字，以及挂在点上的卡片文字。富文本的正文算在这些文字里。图片点因此能被名字和卡片命中。不识别图片里的字。命中若还在某个合集里，打开那个合集并选中这个点。不在任何合集的命中显示「不在任何合集」，不能从搜索跳进去。搜索不查边上的卡片，也不查合集标题。

名字、描述、关系说明和九种卡片，停下输入大约两秒会自己写下。失焦也会写下。⌘S（Ctrl+S）立刻写下还没失焦的改动，包括图上正在输入的名字或标签。图上那一行输入仍等失焦、Enter 或 ⌘S，避免半个名字被收成新的点或边。浏览器不再弹出保存网页。操作区上方显示这一次写入：未保存、保存中、保存成功、保存失败。没有待写的内容时不显示。保存失败时，原来的错误还在；再按 ⌘S 会再试一次。静默保存不会自动重试这一次失败。关上页面前如果还有没写完的内容，浏览器会先问一声。

同一个人开着两处时（两个标签页，或浏览器和桌面壳），一处写下的合集、点、边、卡片，另一处马上能看到。这条通知断了的话，大约五秒再读一次当前这一页。不是两个人同时改同一段文字。两边改了同一处，后写到服务器的留下。这边如果还没写完，不拿服务器上的字盖住正在写的字。

### 工具栏

合集画布左侧有一条竖排工具，毛玻璃，不进壳层的操作区。当前工具用强调色标出。

| 工具 | 快捷键 | 行为 |
| --- | --- | --- |
| 选择 | V | 默认。点选、拖动点、拖空白平移 |
| 文字 | T | 再点击空白处，在那里写下名字，创建文字点 |
| 图片 | I | 打开文件选择。选完回到选择工具 |
| 连线 | L | 从一个点连到另一个点 |
| 子集合 | 无 | 打开弹窗，选择一个合集放进当前画板。不是停留的工具 |
| 属性 | 无 | 打开弹层，改这个合集的连线外观和账号上的画布看法。不改变当前工具 |

图片是一次动作，不是停留的模式。选完文件，工具回到选择。子集合和属性也不是停留工具，不占用 V、T、I、L。

属性弹层打开时，Esc 先关掉弹层，不取消选中，也不取消正在进行的拖动。弹层没开时，Esc 取消正在进行的拖动、连线或行内输入，并回到选择工具。已经在选择工具上、且没有进行中的操作时，Esc 取消选中。

双击空白只在选择工具下创建文字点。

拖空白处仍是平移。滚轮平移，捏合或 ⌘/ctrl 加滚轮缩放。右下角和右键空白都能放大、缩小、适应屏幕。拖点、新建、改名、改标签、换图，都保持当前的平移和缩放。进入这个合集时适应一次屏幕。

焦点在文稿、输入框或笔记里时，画布的快捷键不生效。⌘S 仍保存正在写的内容。

### 右键

右键空白、点或边，弹出各自的菜单。点在预览、缩放条、小地图或正在输入的名字上，不弹出这套菜单。Esc 先关掉菜单。

合集画布：

| 位置 | 菜单 |
| --- | --- |
| 空白 | 添加文字点、添加图片、插入子集合、放大、缩小、适应屏幕 |
| 点 | 改名、建下级、建同级、从这里连线、移出这个合集、删除这个点 |
| 边 | 改标签、删除关系 |
| 收起的子集合 | 展开、移出这个合集 |
| 展开的子集合边框 | 收起、移出这个合集 |

添加文字点写在右键的位置，和双击空白一样。添加图片也落在右键的位置，多张向右下错开。正在上传的点没有菜单。从这里连线先记下起点，再点另一个点写标签。删除这个点和删除关系先弹出原来的确认。移出这个合集不删除点。

全貌：

| 位置 | 菜单 |
| --- | --- |
| 空白 | 新建合集、放大、缩小、适应屏幕 |
| 合集 | 打开、删除合集 |
| 合集边 | 删除关系 |

删除合集走原来的确认。Delete 和 Backspace 仍然不删除合集，也不移出子集合。全貌上的合集边仍在检查器里改标签。

### 子集合

合集画布可以把另一个合集放进来，在这一张图里查看和编辑。放进来的仍是原来的合集。同一个子集合在一个父合集里只放一次。它可以放进多个父合集，位置各自记住。不能放进自己。不能绕回去：甲放进乙之后，乙不能再放进甲，沿着放入关系走回去也不行。

这一步只看一层。子集合里再放的合集，在父合集上不展开。要看那一层，打开那个子集合。

放入前先看两者有没有关系。下面两条有一条即可：

- 两边已经有合集边，从哪边指向哪边都行。
- 一个合集里的点，已经连到另一个合集里的点。

有这些，直接放入。都没有，必须先写下关系，去掉首尾空白后 1 到 40 个字。这条关系记成从当前合集指向所选合集的合集边，全貌上也能看到。

弹窗列出可以放入的合集。已经放进来的、自己、以及会绕回去的，不出现。

放进来默认展开。展开时，父合集上有一块虚线边框，标题是子集合的名字。已有合集边时，关系写在标题旁。边框里是子集合自己的点和边。点仍用它在子集合里的坐标，整块跟着边框移动。拖边框只改这块在父合集上的锚点，不改子集合里点的相对位置。在边框里添加、拖动、改名、连线、放图片，改的都是子集合。

收起后，这块变成一个点，名字是子集合的标题，下面写「子集合 · N 个点」。双击或右键「展开」再打开。右键「移出这个合集」只拿掉这块放入，不删子集合，也不删已经建立的合集边和点边。

点与合集之间仍然没有边。收起的子集合不能当作连线的起点或终点。

一端在父合集、一端在子集合里的点边：展开时画在两端之间，收起时接到那个点上。子集合内部的边只在展开时出现在边框里。已经是父合集成员的点，不在边框里再画一次。同一个点若只出现在多个子集合里，只画在先放进来的那一个里。

全貌不画这块边框。删掉父合集或子集合时，放入关系一起去掉，另一头的合集还在。

### 连线

两种起手：

1. 选择工具下，悬停点时四边中点各有一个蓝色圆点。从任一圆点拖到另一个点上。
2. 连线工具下，先点起点再点终点，或从一个点拖到另一个点。

没有落到另一个点上，就取消，不创建边。落到自己身上，不创建。

创建前，在连线中点行内写标签。写完才创建。取消则不创建。与已有边的起点、终点、标签都相同，不创建，提示「这条关系已经有了」。

新建的边用这个合集当前的连线外观。走线、线型和箭头见「画布设置」。线画在点的下面。点可以压住线；线的可点区域沿着实际路径，仍然能被点到。

拖动连线、还没落到终点时，临时线是直线、虚线，颜色和粗细跟这个合集一致。它不走曲线或折线。Esc 取消这根临时线。

### 改线

单击边：选中它，右侧打开关系检查器。

双击边，或选中边后按 Enter：在线的中点行内改标签。输入框里先放着现在的标签。改成另一句合法标签就保存。清空、只剩空白、或与原来相同，都保持原标签。改成已经存在的同一条关系时不保存，提示「这条关系已经有了」。

检查器里改标签仍然有效。卡片仍在检查器里添加。双击边只改标签。选中一条边时，线保留这个合集的外观，并加一圈强调色。悬停时线色加深。

### 画布设置

合集画布左侧，「连线」下面有一条分隔，再放「属性」。点开后，弹层贴在工具栏右边，毛玻璃，分「这个合集」和「所有合集」。再点「属性」、按 Esc、或点弹层以外，弹层关闭。点在点或边上时，选中照常发生。改完立刻画出来。空合集也能改，下一次连上的边用这套外观。全貌没有这条按钮。

这些写入不进入「未保存 / 保存中」，离开页面时也不为此再问。失败时，刚动过的那一项回到写入前的值，错误出现在画布上原有的提示里。另一个窗口不要求当场跟着变，下次打开时一致。

**这个合集**的连线外观记在合集上。这个合集里能看见的边一起变。同一条边出现在另一个合集时，用那个合集自己的外观。不改边上的标签和卡片。删掉合集时，这份外观一起去掉。

| 项目 | 选项 | 默认 |
| --- | --- | --- |
| 线型 | 实线、虚线、点线 | 实线 |
| 粗细 | 细、中、粗 | 细 |
| 颜色 | 灰、蓝、绿、红 | 灰 |
| 箭头 | 有、无 | 有 |

颜色只用这四色，没有自由取色。粗细三档固定，没有滑杆。关掉箭头后，线仍从起点边框接到终点边框，起点和终点还在。再打开，箭头回到终点。

**所有合集**的看法记在账号上。网页和桌面端登录同一账号是同一套。删掉合集不删这套看法。

| 项目 | 选项 | 默认 |
| --- | --- | --- |
| 走线 | 直线、曲线、折线 | 直线 |
| 点阵 | 开、关 | 开 |
| 吸附 | 开、关 | 关 |
| 标签 | 始终、悬停或选中 | 始终 |
| 卡片标记 | 开、关 | 开 |
| 小地图 | 开、关 | 开 |
| 下级方向 | 上、下、左、右 | 下 |

走线只作用于合集画布。切换后立刻重画，不改点已经记下的位置。直线沿两点中心，从边框接到边框。曲线在同样的两端之间轻度弯出，不能拖控制点。折线从边框水平或垂直离开，再水平或垂直进入，圆角拐弯，拐弯尽量少。同一对点上的多条边，以及方向相反的两条边，仍按现在的间距错开。标签在看得见的中点；折线的标签在较长的那一段，箭头沿到达方向。箭头的尖端接在终点边框上，线停在箭头底部，不伸进箭头里。全貌保持直线。

点阵铺在画布背景上，全貌和合集都有。格子在世界坐标上，间距 16。点的位置跟着平移和缩放走，点的大小保持约 1.5 屏幕像素。关掉后背景是纯浅灰。点阵和吸附互不影响。

吸附步长 16，只影响合集里点的左上角。打开时，拖动中贴到最近的格点，松手记下这个格点。双击空白、右键添加文字点、文字工具点击、拖入图片、右键添加图片、粘贴图片、Tab 建下级、Enter 建同级，以及还没有位置的点落在视野中心，也同样贴格。第一次打开、全部点都还没有位置时，按自动排布记下，这一次不吸附。已经摆好的点保持原位，直到下一次被拖动。图片宽度不吸附。关掉之后，新的拖动停在松手处。全貌不能拖点，没有吸附。

标签指边上的关系文字。点的名字、合集的标题始终显示。「悬停或选中」时，没悬停也没选中的边不画标签，也不画标签旁边的卡片数。正在改标签时，输入框照常出现。这个开关对合集和全貌都生效。

卡片标记关掉后，合集画布上不画点的卡片数、类型色点，以及边标签旁的数字。悬停预览和检查器里的卡片还在。全貌上合集的成员点数保持显示。

小地图关掉后，合集和全貌右下角都不画小地图。缩放、比例和适应屏幕还在。

下级方向只影响合集里新建下级的位置，包括 Tab 和右键「建下级」。下：放在选中点正下方，左边对齐；这个位置被挡住时，向右让开一个文字点。上：正上方，挡住时向右让。右：右侧，上边对齐，挡住时向下让。左：左侧，上边对齐，挡住时向下让。Enter 建同级始终在正下方，挡住时继续向下。全貌没有建下级。

### 图片怎么进来

三种方式都创建新的图片点。已有的文字点保持为文字点。

1. 工具栏的图片，或按 I：选择文件，点出现在当前视野中心。一次选多张时，从中心向右下错开。
2. 把图片文件拖进画布：落在松手的位置。多张同样错开。拖到一个已有的点上，仍然新建，不替换那个点。进行中的连线或行内输入被取消。
3. 焦点在画布上时 ⌘V。剪贴板里是图片，就贴到视野中心。焦点在输入框、笔记或检查器里时，粘贴留给那个字段。焦点在富文本里时，⌘V 交给文稿。

格式是 JPEG、PNG、WebP、GIF。GIF 按浏览器自己的方式播放。单张不超过 10 MB。

放进来的不是这些格式时，不创建点，提示「只能放入 JPEG、PNG、WebP 或 GIF」。超过 10 MB 时，不创建点，提示「图片不能超过 10 MB」。

上传时先放一个占位，写着文件名和「正在上传」。占位可以拖。失败则去掉占位，不留下点。

名字默认取文件名，去掉扩展名。去掉之后为空，就叫「图片」。长于 80 个字时截到 80 个字。之后可以改名。

选中图片点后，检查器里可以更换图片。更换用同一套格式和大小。新图成功之前，画板上仍是旧图。更换后，这个点在别的合集里的脸也换了；那边的位置和宽度不变。

文字点沿用现在的尺寸。图片默认宽 220，高度按原图比例。选中图片点时，右下角拖动改变宽度，宽度在 120 到 480 之间，比例不变。这个宽度只属于当前合集。

### 富文本

富文本只挂在点上。接口若把富文本挂到边上，拒绝，不创建。

现有的笔记卡保持短文，存 HTML。不把旧笔记改成富文本。一篇要写长、要插图和表格时，另加富文本卡。

写作能力对齐 Inwit 文稿编辑器里用来写字的那一部分。每张卡片顶部有一条工具。按钮是图标，悬停显示名称：

- 撤销、重做。只撤销这张卡片里刚写的内容。刷新之后，这次历史消失。
- 粗体、斜体、删除线、清除格式。
- 字号：默认，以及 12、13、14、15、16、18、20、22、24、28、32、36。
- 字色和字的底色：一组固定颜色，也可以自己填 `#RRGGBB`。
- 对齐：居左、居中、居右，收在一个下拉里，按钮和选项都是图标，悬停显示名称。
- 正文和六级标题。
- 无序列表、有序列表、可嵌套的任务列表。
- 代码块。语言在这块代码上选，按语言高亮。
- 表格。放在代码块后面。
- 公式。紧挨表格。
- 链接。编辑时单击不跳走；打开时新开一页。地址会自动识别。
- 图片、分割线、Mermaid 图。
- 引用。放在工具条最后。
- 光标在表格里时，另出一条居中的表格条：上下加行、左右加列、删行、删列、合并、拆分、表头行、表头列、单元格底色、删除表格。

公式用 LaTeX。单独一行，或用 `$$` 包住，就独占一段；否则嵌在句子里。排不出时显示原来的 LaTeX。

Mermaid 画不出来时，留下源码，并写「这张图没有画出来」。卡片的其余部分照常可编辑。

行首输入 `#`、`-`、`1.`、`>` 会转成对应的块，和笔记卡一样。粘贴带格式的文字时，保留编辑器认得出的格式：标题、列表、引用、代码、表格、对齐、粗体、斜体、删除线、下划线、上标、下标、行内代码、链接、字色、底色和字号。字号按最近的一档保留。剪贴板里同时有纯文本时，不用纯文本盖掉这些格式。没有这些格式时，再按 Markdown 解析：标题、列表、引用、代码、表格、公式、粗体、斜体、删除线、行内代码和链接转成对应的格式，不留下记号。围栏语言是 mermaid 时转成 Mermaid 图。认不出的文字原样留下。

文稿里的图片用工具插入，或拖进、粘贴进这张卡片。格式和大小与画板上的图片点相同：JPEG、PNG、WebP、GIF，单张不超过 10 MB。不合规则时提示相同：「只能放入 JPEG、PNG、WebP 或 GIF」，或「图片不能超过 10 MB」。插进文稿的图片属于这张卡片，不是一个新的图片点。拖到画布空白处仍是新建图片点。拖到已有的点上仍是新建图片点。

删掉这张卡片，里面的图片一起删掉。删掉点，它的富文本和这些图片一起删掉。换点的脸部图片不影响文稿里的图。

停止输入大约一秒后保存。失焦再保存一次。⌘S 立刻保存。内容没变不保存。文稿过大、存不下时不覆盖旧内容，提示「这篇文稿太大了」。

图上的类型色点包含富文本。悬停摘录若轮到这张卡，用它正文的开头，不把内部结构摊开。

## 图

两张图都画出全部对象，都用自定义 SVG，放在 `GraphViewport` 里，绘制在 `BoardCanvas` 中。点一个点不会把图收成这一跳的上下游。

- 全貌画出每一个合集，以及合集之间的边。合集上标出成员点数。全貌页仍自动排布：没有边，或者图里有环时，合集横排；没有环时，按边从左到右分层。
- 合集图画出每一个成员点，以及两端都在这个合集里的边。一端不在这张图上的边不出现。放进来的子集合按上一节画出。点上标出卡片数和卡片类型的色点，边标签旁标出边上的卡片数。位置按合集记，打开之后不再自动重排。

地址 `?node=` 和 `?edge=` 会在合集图加载后选中对应的点或边。之后的点击不把选择写回地址。

## 界面

壳层是一块浮在画布上方的操作区加全出血画布，没有边栏。壳层和登录不变。

- 保存状态在操作区上方正中：未保存、保存中、保存成功、保存失败。没有待写的内容时不显示。
- 操作区：毛玻璃横条，居中浮在画布顶部，从左到右是用户头像、合集切换、搜索 ⌘K、设置。头像点开账号区：头像、用户名、更换或移除头像、修改用户名、登出。合集切换列出全部合集和点数，顶部是「全貌图」，底部是「新建合集 ⌘N」。设置里放「回到全貌图」。
- 画布全出血，浅灰底。点阵默认打开，全貌和合集都有，可在属性里关掉。新建、连线、改名都在图上直接做；当前合集和点数显示在操作区的合集切换上。合集页左侧另有画板工具栏。
- 选中后，右侧浮出玻璃检查器。

点的检查器默认宽 640。左缘可以拖，宽度在 480 到 880 之间，记在这台浏览器里，下次打开还在。窗口不够时，检查器变窄，画布至少留下 320。边的检查器、合集边的检查器、全貌页上的检查器仍宽 340。

- 全貌上的合集可以改名、打开、连到另一个合集、看到相关的边、删除。合集边是卡片和删除。
- 文字点的检查器：改名、描述、卡片、放入其他合集、移出这个合集、删除这个点。富文本卡片排在卡片栈里，编辑区至少高 360，随内容变高。写到这张卡片时，它的工具条粘在检查器顶部；滚到别的卡片后让开。
- 图片点多一块预览和「更换图片」。描述、卡片、成员和删除与文字点同一套。
- 边的检查器：两端名字、标签、原来的八种卡片、删除这条边。没有富文本。删掉边时，边上的卡片一起去掉。

删除在检查器里确认后执行。选中点、点边或合集边时，Backspace 或 Delete 打开同一条确认，确认后才删。这两个键不删除合集。焦点在输入框、文本框或富文本里时，这两个键只编辑文字。确认弹层盖住整页，取消和删除都在画面里。

样式跟组件放在同一目录，令牌在 `apps/web/src/foundation/`。浅色分层灰、毛玻璃、单灰蓝强调。界面用无衬线，笔记和富文本正文用衬线，代码用等宽。九种卡片的颜色在 `apps/web/src/features/cards/card-meta.ts` 注册，没有点的类型色标。

## 当前不做

领域、点的类型、扇区、固定关系词表、能力、证据、复习、今日、练习、建议托盘、导入导出、撤销栈、一跳星图、按领域切换卡片。这些如果以后还要，先做成一种新卡片，或先改本文再改代码。

撤销栈仍然不做。富文本卡片内部的撤销除外，只撤销这张卡片里刚写的内容，刷新之后消失。画板一级没有撤销。

另外不做：

- 全貌页自由摆放，或给合集上传图片
- 把图片做成一种卡片
- 文字点改大小、改颜色、改形状
- 框选、多选、成组、对齐
- 给单独一条边或一个点改线型、粗细、颜色
- 自由取色，或用滑杆调粗细
- 拖曲线的控制点
- 每个合集各存一套走线、点阵或吸附
- 全貌上的合集边改成曲线、折线、虚线，或去掉箭头
- 手绘、箭头以外的形状
- SVG、HEIC、视频，或一个点上放多张图
- 识别图片中的文字
- 不经确认直接删除
- 点与合集之间的边
- 在父合集上展开子集合里的下一层
- 把已有笔记卡转成富文本，或让富文本挂到边和合集边上
- 文稿里的视频、分页、批注、实体提及、文内查找
- Inwit 的复习、摘录、知识地图，以及直接依赖 Inwit 仓库里的包

登录保留，注册开放。

## 验收

1. 打开还没有位置的合集，点的相对位置按自动排布记下。拖动一个点后刷新，它留在新位置，其他点不动。打开另一个包含这个点的合集，那边的位置不变。
2. 双击空白，文字点出现在双击处。拖右侧圆点到另一个点，写下标签，边出现。双击这条边改标签，图上和检查器里一起变。
3. 把一张 PNG 拖进画布，图片点出现在落点，名字来自文件名。把它连到一个文字点。两边都能加原来的八种卡片。点上可以加富文本。
4. 拖进一个非图片文件，或一张超过 10 MB 的图，不产生点，并看到对应提示。不合格式时提示「只能放入 JPEG、PNG、WebP 或 GIF」。
5. 更换图片后，这个点在另一个合集里的脸也换了；那边的位置和宽度不变。
6. 拖动点或新建时，当前缩放和平移保持不动。
7. 全貌页仍自动排布。合集之间的边在检查器里改标签。没有这套工具栏，也不能上传图片。
8. 在点上添加富文本，写入标题、列表、一张表、一块代码、一条公式和一张图。刷新后都还在。用正文里的一句去搜索，能打开这个点。文稿过大时提示「这篇文稿太大了」，旧内容还在。
9. 边的添加按钮里没有富文本。富文本只挂在点上。
10. 点的检查器默认宽 640，比边的检查器宽。边的检查器宽 340。拖窄或拖宽后刷新，宽度还在。窗口变窄时，画布至少留下 320。
11. 图片拖进富文本里，进的是这篇文稿。图片拖进画布空白处，出现的是一个新的图片点。
12. 选中一个点或一条边，按 Delete 或 Backspace，出现删除确认。取消和删除都看得见。取消后它还在。正在输入时，这两个键只编辑文字。选中合集时，这两个键不弹出删除确认。
13. 合集画布左侧有「属性」。把一个合集改成红色虚线、粗、无箭头后，这个合集里的边都是这个样子，另一个合集仍是细灰实线、有箭头。走线、点阵、吸附、标签、卡片标记、小地图记在账号上，换端登录后还在。点阵默认看得见。全貌没有「属性」，合集之间的边仍是直线。设置失败时那一项回到原值，页面不因此出现「未保存」。
14. 右键空白、点和边，菜单各自不同。合集里右键点可以改名、建下级、建同级、连线、移出和删除；右键边可以改标签和删除。删除仍先确认。全貌右键合集可以打开或删除，右键合集边只删除。Delete 仍不删除合集。
15. 在合集里插入另一个合集。两者没有关系时，不写关系就放不进去；写下关系后，全貌出现这条合集边，当前画布出现带边框的子集合。拖动边框里的点，再打开那个子集合，位置已经变了。收起后变成一个点，再展开边框还在。移出后，子集合和那条关系都还在。已经有合集边或跨集合的点边时，不用再写关系。不能把合集放进自己，也不能绕回去。
