## 1. 拓扑

单用户桌面 Web。一个服务端进程。产品请求不经过 Meilisearch、Qdrant、DashScope，也没有独立 worker。

```
浏览器 SPA (Vite 6 / React 19, http://localhost:5173)
   │ 同源 /api ，开发期 Vite 代理到 127.0.0.1:3000
   ▼
Fastify 5 (apps/server, 127.0.0.1:3000)
   └── PostgreSQL   DATABASE_URL（Drizzle + pg）
```

Vite 开发服务器监听 `[::1]:5173`。用 `localhost` 访问。`/health` 不需要登录。

## 2. 仓库

pnpm workspace，Node ≥ 22，TypeScript 5.9，ESM，Vitest 3，ESLint 9。

```
apps/server     Fastify、Drizzle、认证、图的读写和 ILIKE 搜索
apps/web        React SPA。产品页在 src/pages，样式在 src/workspace.css
packages/dto    Zod 契约，server 和 web 共用。图的契约在 src/graph.ts
packages/doc-schema   粘贴夹具和块 schema。产品页不读写它
packages/markdown     doc-schema 的 Markdown 解析
packages/search       召回条目和 RRF 的纯函数。服务端不调用
```

产品页的状态在 `@rabjs/react` 的 `SessionService` 和 `LibraryService`。图是自定义 SVG，坐标在 `apps/web/src/lib/board-layout.ts`，画布是 `GraphViewport`。不用 React Flow。

Tiptap 3.31.3 由根 `package.json` 的 overrides 锁定，用于笔记卡的富文本、`/paste-bench` 和 `packages/doc-schema`。公式卡片用 KaTeX，代码卡片用 highlight.js 的 common 包。服务端依赖里没有 `@unfold/doc-schema`、`@unfold/search`、`ts-fsrs`。

`packages/dto` 仍导出 `normalizeName`（NFKC、去首尾空白、折叠空白、英文小写）。图的创建和搜索不用它。点的名字只做 trim，允许重名。

## 3. 环境

密钥只在 `apps/server/.env`。文档和代码里只出现变量名。

| 变量 | 谁读取 |
| --- | --- |
| `DATABASE_URL` | 服务端、迁移、种子 |
| `SESSION_SECRET` | Cookie 签名 |
| `UNFOLD_ENV` | `production` 时登录 Cookie 加 `Secure` |
| `SEED_USERNAME` | `pnpm --filter @unfold/server seed`，以及服务端集成测试 |
| `SEED_PASSWORD` | 同上。不要写进文档、日志或提交 |

服务端启动只要求前三项。`loadConfig()` 不读取检索或模型相关变量。

迁移：`pnpm --filter @unfold/server migrate`。Drizzle 按 `apps/server/drizzle/meta/_journal.json` 执行 SQL。`0000` 到 `0008` 是重构前的表，新库仍会先执行它们。`0009_graph_core.sql` 删掉这些业务表（保留 `users`），再创建现在的图。`0010_node_description.sql` 给 `nodes` 加 `description`。已迁移过的库只会再跑尚未记录的文件。迁移可以连续执行两次。

种子用户用 argon2。注册接口没有开放。

## 4. 表

业务行都带 `user_id`。主键是 UUID，`gen_random_uuid()`。除成员关系外，删除写 `deleted_at`。另一位用户的 id 查不到，返回 404。

| 表 | 字段 | 约束 |
| --- | --- | --- |
| `users` | `username`，`password_hash` | `username` 唯一 |
| `collections` | `title` | 无名称唯一约束 |
| `nodes` | `name`，`description` | 无名称唯一约束。描述 trim 后不超过 160 字 |
| `memberships` | `collection_id`，`node_id` | 联合主键。删除是物理删除 |
| `edges` | `from_id`，`to_id`，`label` | 禁止自环；标签 trim 后非空；未删除行上 `(user_id, from_id, to_id, label)` 唯一 |
| `collection_edges` | 同上，两端是合集 | 同上 |
| `cards` | `owner_kind`，`owner_id`，`card_type`，`position`，`content jsonb` | `owner_kind ∈ node/edge/collection_edge`；`card_type` 为产品文档里的八种。`content` 的键由类型决定，值都是字符串 |

点与合集之间没有边。删除合集时，软删它参与的合集边和这些边上的卡片，并物理删除它的成员关系，不删除点。删除点时，软删它的卡片、它参与的点边和这些边上的卡片，并物理删除它的成员关系。删除一条边时，软删挂在它上面的卡片。

## 5. HTTP

Cookie 名 `unfold_session`，签名，HttpOnly，SameSite=Lax。错误体是 `{ "error": { "code", "message" } }`。未登录是 401 `unauthenticated`。请求体不合法是 400 `invalid_body`。登录失败是 401 `invalid_credentials`。登录每分钟最多 30 次，超出是 429 `rate_limited`。

创建返回 201。读取和更新返回 200。删除、加入成员、移出成员返回 204。重复加入同一个成员也返回 204。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/login` | `{ username, password }` → `{ username }` |
| POST | `/api/logout` | 清 Cookie |
| GET | `/api/me` | `{ username }` |
| GET | `/health` | `{ ok: true }` |
| POST | `/api/collections` | `{ title }` |
| GET | `/api/collections` | `{ collections }`，每条带 `nodeCount` |
| PATCH | `/api/collections/:id` | `{ title }` |
| DELETE | `/api/collections/:id` | |
| GET | `/api/library` | 全部合集（带 `nodeCount`）和合集边（带 `cardCount`） |
| GET | `/api/collections/:id/graph` | 成员点（带 `cardCount`、`cardTypes`），以及两端都是成员的点边（带 `cardCount`） |
| POST | `/api/collections/:id/nodes` | `{ name }`，创建点并加入该合集 |
| POST | `/api/collections/:id/members` | `{ nodeId }` |
| DELETE | `/api/collections/:id/members/:nodeId` | 移出，不删点 |
| GET | `/api/nodes/:id` | 点、所在合集、点上的卡片 |
| PATCH | `/api/nodes/:id` | `{ name? }` 或 `{ description? }`，至少给一个 |
| DELETE | `/api/nodes/:id` | |
| POST | `/api/edges` | `{ fromId, toId, label }` |
| GET | `/api/edges/:id` | 含两端名字和卡片 |
| PATCH | `/api/edges/:id` | `{ label }` |
| DELETE | `/api/edges/:id` | |
| POST | `/api/collection-edges` | `{ fromId, toId, label }` |
| GET | `/api/collection-edges/:id` | 含两端标题和卡片 |
| PATCH | `/api/collection-edges/:id` | `{ label }` |
| DELETE | `/api/collection-edges/:id` | |
| POST | `/api/cards` | `{ ownerKind, ownerId, type, content }` |
| PATCH | `/api/cards/:id` | `{ content }`。按已存类型校验，不能改类型 |
| DELETE | `/api/cards/:id` | |
| GET | `/api/search?q=` | `{ hits }`，最多 30 条 |

自环返回 400，文案「不能连到自己」。重复的活动边返回 409 `conflict`，文案「这条关系已经有了」。找不到时的 `code` 是 `not_found`。

契约在 `packages/dto/src/graph.ts`。卡片内容是 `z.strictObject`，响应里的卡片字段名是 `type`，对应表列 `card_type`。

## 6. 搜索

`GET /api/search` 用 PostgreSQL `ILIKE`。匹配点的 `name`，以及 `owner_kind = 'node'` 的卡片 `content::text`。`%`、`_`、`\` 会转义。空查询返回空列表。

每条命中是 `{ nodeId, name, collectionId, collectionTitle, snippet }`。合集取该点所属合集里 `created_at` 最早的一个未删除合集。没有合集时这两个字段是空字符串。摘录优先用点名；点名未命中时，用第一张命中卡片里的字符串拼起来，截到 80 个码位。

## 7. 前端路由

| 路径 | 页面 |
| --- | --- |
| `/` | 恢复会话后去 `/library`，否则去 `/login` |
| `/login` | 登录 |
| `/library` | 合集全貌 |
| `/c/:id` | 一个合集的全貌 |
| `/paste-bench` | 粘贴夹具，在壳层之外 |

`LibraryPage` 和 `CollectionPage` 共用 `LibraryService`。壳层在两者之间切换，两页不会同时挂载。

`layoutBoard`：没有边，或存在环，或 Kahn 分层放不完所有点时，横排（宽 168，高 56，间距 36，原点 32,48）。无环时从左到右分层，层距 220，纵向间距 28。自环和端点不在图上的边不参与布局。

`BoardCanvas`：点阵背景、节点上的描述行、卡片计数徽标和类型色点、边标签旁的卡片数。双击空白调 `onBackgroundDoubleClick` 内联创建，双击节点内联改名（全貌页是打开合集），从节点右缘手柄拖到另一个节点连线，悬停 450ms 出预览（`LibraryService.loadPeek`，不动 `nodeDetail`）。方向键按空间距离移动选中，Enter 打开或改名，Esc 取消选中。世界坐标换算用内层 `<g>` 的 `getScreenCTM()`。

笔记卡用 Tiptap（`@tiptap/starter-kit`）做富文本，`body` 存 HTML，失焦保存，搜索摘录在服务端去标签。代码卡编辑时是 textarea，失焦后用 highlight.js 渲染高亮块，点击回到编辑。时段和事件的日期用 `UDateField`（可手输自由文本，也可开日历选 `YYYY-MM-DD`）。

## 8. 检查

`pnpm test`、`pnpm typecheck`、`pnpm lint`。服务端集成测试通过 `buildApp` 和 `inject` 打到 `DATABASE_URL` 指向的库，使用种子用户。图的集成测试在结束时删除自己创建的点和合集。

改产品语义时先改 `docs/prd/2026-10-25-graph.md`，再改这里和代码。不要按已删除的扇形 PRD、阶段计划、阅读设计或原型恢复领域、点类型、扇区、能力或一跳星图。
