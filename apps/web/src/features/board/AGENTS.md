# SVG 画布

- 本目录负责视口、点边渲染、布局与画布交互；业务持久化通过图谱状态层完成，不在渲染组件里复制领域 CRUD。
- 保持自定义 SVG 实现，不引入 React Flow 替换画布。
- 世界坐标与屏幕坐标转换统一基于 `GraphViewport` 内层 `<g>` 的 `getScreenCTM()`，拖拽、缩放和图片落点使用同一坐标体系。
- 自动排布集中在 `board-layout.ts`，保持 `layoutBoard` 等布局函数可独立单测。
- 位置、层级和图片宽度属于点在合集内的摆放状态；不要当作跨合集共享的点属性。
- 画布图片导入复用 `image-intake.ts` 的格式、大小与落点逻辑；拖入画布创建图片点，拖入富文本的图片归卡片编辑器处理。
- 图上的创建／改名／改标签行内输入等待失焦、Enter 或 ⌘S，不能被普通草稿的静默保存提前提交。

## 指令文件双向同步

- 同目录的 `AGENTS.md` 与 `CLAUDE.md` 是同一份项目规则，内容必须保持完全一致。
- 后续 Agent 修改任意一方时，必须在同一次变更中同步更新另一方；新增、移动或删除项目级指令文件时也要成对处理。
- 完成前逐对检查内容一致；若已有差异，先核对实际代码与用户要求再合并，不能直接覆盖另一方独有的有效规则。
